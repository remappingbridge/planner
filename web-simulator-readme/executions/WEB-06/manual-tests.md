# WEB-06 — Numbered, manual production-browser acceptance tests

**Status:** PENDING OPERATOR TEST AND ACCEPTANCE. Do not run Debian, local HTML, Node/npm or firmware flash commands. Website: https://remappingbridge.github.io/ · Browser tests: https://remappingbridge.github.io/tests/.

The HAT can be controlled by clicking the on-screen joystick/buttons. Keyboard equivalence: arrow keys = joystick directions, Enter/Space = joystick press, letters A/B/X/Y = HAT buttons. Prefer clicking virtual buttons when testing browser scroll or if focus is in an input field. The **Clear All Virtual Data** button deletes **only simulated mice stored in the current browser**, so keep previously saved simulations if desired.

1. **Sticky while scrolling:** open the website at normal zoom. Scroll down to **Virtual Mouse Lab** and then **Virtual Session** with the mouse wheel or trackpad. **Expected:** HAT remains visible at the top, while the lower settings move normally and remain usable; no black bars or input panels hidden permanently.
2. **New physical panel layout:** inspect the stationary HAT. **Expected:** left joystick + compact square LCD + one-column **A, B, X, Y** right keys + device brand/virtual status/Pico/LCD specifications at the **far right**, metadata vertically constrained to LCD top and bottom. No old branding row above or footer below the square. Buttons have less rounding and fit the LCD height.
3. **Viewport/zoom:** repeat test 1 at 150% and 200% Firefox zoom and at a narrow responsive viewport/mobile portrait. **Expected:** HAT does not cover the entire visible area or force a horizontal scrollbar; you can still operate the lower controls. Report any clipping, unreadable text, stuck overlap or impossible scrolling.
4. **Baseline/guide:** inspect the LCD and guide after scrolling. **Expected:** Gentle magenta `#300c39` stays fixed (no background selector), original title magenta and foreground tones remain unchanged, and the KEY B/KEY Y English guide remains in document below the sticky device.
5. **Pair two independent mice:** in Virtual Mouse Lab, enter `Mouse Alpha` → **Start Pair New** → **Complete Successfully**. Repeat for `Mouse Beta`. **Expected:** `2 / 8 saved`, no real Bluetooth permission, separate IDs. **Connected demo** shows a navigable HOME if the first connection shows the didactic FIRST MOUSE CONNECTED tutorial.
6. **Edit draft without Apply:** with `Mouse Beta` connected, choose **Connected demo**, joystick **PRESS** to enter `REMAPPING OPTIONS`, joystick **DOWN** once and **PRESS** for `EDIT CUSTOM`. Joystick **PRESS** enters `LEFT WILL BECOME`; **DOWN five times**, then **A** selects `MODIFIER` as a **draft**. **Expected:** return to EDIT CUSTOM; Virtual Mouse Lab still reports the previously applied profile until **A** on EDIT CUSTOM. Press **B** to cancel; no saved Custom profile or Current/Cyan indicator must appear.
7. **Apply Custom:** repeat test 6 and press **A in EDIT CUSTOM** after drafting. **Expected:** profile summary changes to `CUSTOM`, applied LEFT is Modifier, REMAPPING OPTIONS now highlights the applied Custom/Modifier rows cyan. Go back, reload and reconnect Mouse Beta: applied modifier remains saved.
8. **Exclusive Modifier:** in applied Custom for Mouse Beta enter EDIT CUSTOM, select the **FORWARD** source (fourth entry) and set its target `MODIFIER` with **A**, then **A in EDIT CUSTOM** to apply. **Expected:** FORWARD becomes Modifier, LEFT returns to LEFT (not RIGHT, not BACKWARD), and only one source is Modifier.
9. **Horizontal DPI:** from Connected Home choose **MOVEMENT OPTIONS** (second HOME choice), press the joystick on `HORIZONTAL DPI`. Use joystick **RIGHT** to enter FAST, **DOWN once** for **1.5x**, then **A** to Apply. **Expected:** the lab summary shows **H 1.5x**, and the Movement Options page returns. Press **B** on an alternative draft choice before A: H must remain 1.5x.
10. **Vertical DPI and rotation:** on Movement Options select `VERTICAL DPI` → choose **0.5x** in the SLOW group (third value) → **A**. Select `ROTATION` (third Movement option), choose **90-DEGREE** → **A**. **Expected:** mouse summary shows **V 0.5x** and **90°**, with H still 1.5x. Reload: values persist.
11. **Isolation between mice:** disconnect Mouse Beta, select Mouse Alpha in the saved list → **Search Saved** → **Complete Successfully**. **Expected:** Mouse Alpha still has original **PASSTHROUGH, H 1x, V 1x, 0°**. Reconnect Beta; its Custom and Movement profile from tests 7–10 return.
12. **Reset only Movement:** with Beta connected, enter MOVEMENT OPTIONS and press **A there** (not inside a DPI page). **Expected:** Beta returns to H 1x, V 1x, 0°, but its applied Custom/Modifier profile stays intact. Mouse Alpha remains unaffected.
13. **Back, Help and Lock:** during navigation, B returns/cancels drafts, X opens contextual Help, Y blanks the LCD when permitted; press/release any HAT control to unlock. **Expected:** unlock returns to Home without executing that key. FIRST MOUSE tutorial remains an explicit didactic exception.
14. **Browser-native automated test page:** open https://remappingbridge.github.io/tests/ after publication. **Expected:** `165/165 checks passed.` If not, report the exact English failure label and your browser/version.

**Decision:** WEB-06 remains pending until the operator explicitly accepts it. Do not begin WEB-07. If a step fails, correct this WEB-06 gate and republish for production testing.
