# WEB-09 — Numbered operator tests in production browser

**Gate status:** OPERATOR ACCEPTANCE PENDING. Open https://remappingbridge.github.io/ and https://remappingbridge.github.io/tests/ in the real browser. No local Debian terminal, Node/npm or Pico firmware update is needed.

1. **Bottom-right technical metadata:** view the HAT at normal zoom. **Expected:** PICO 2 W, LCD 240 × 240 and 9 HAT CONTROLS appear together at the **bottom-right corner inside their right-hand panel**, not centered vertically. Text is right-aligned; each line remains readable.
2. **Preserved other corners:** **Expected:** REMAPPINGBRIDGE remains top-left, VIRTUAL DEVICE and yellow dot remain bottom-left, left joystick, square LCD and vertical A/B/X/Y remain aligned.
3. **Removed dispensable controls:** scroll all the way down the app. **Expected:** no `DISPLAY CONTROLS · WEB-08`, **no `LCD appearance`** section, no brightness slider and no Compact/Standard/Spacious density menu anywhere.
4. **Lock still works:** select Connected demo, press Y, then press/release any HAT button. **Expected:** LCD goes fully black while locked and restores the source screen after unlocking. No optional brightness setting or shell color change.
5. **Sticky/zoom:** scroll through lower panels at Firefox zoom 100%, 150% and 200%. **Expected:** HAT stays visible without hiding the lower controls; bottom-right specs and two left-corner labels don't overlap LCD or A/B/X/Y. Try narrow 320px and 768px widths when feasible.
6. **Inspector collapsed by default:** find `Diagnostic Inspector · scenarios and local evidence`. **Expected:** it occupies only a collapsed single-line entry until opened, without altering the live HAT screen.
7. **First-use and Connected scenario:** expand Inspector, choose First use, click Run; then Connected. **Expected:** independent diagnostic 240×240 preview shows SEARCHING FIRST then HOME, with screen ID, logical dimensions and a state hash. The main HAT itself remains unchanged.
8. **Deterministic hash:** run Connected twice in succession. **Expected:** the 8-digit hexadecimal state hash is identical each time; selecting different scenarios changes it.
9. **Multi and Remove isolation:** run Two Mice and Remove Saved Mouse. **Expected:** two distinct simulated devices then one saved; your previously created normal Virtual Mouse Lab bonds remain intact when you leave the Inspector/reload.
10. **Failed/stale and timeout:** run `Stale response and failed pairing` and `Saved mouse search timeout`. **Expected:** first shows failed-pair Retry with stale response ignored and no new bond; timeout shows HOME RETRY. The Inspector event timeline records both.
11. **Custom Movement and Shortcuts:** run the scenarios `Custom profile and Movement` and `Modifier shortcuts and assignments`. **Expected:** the separate diagnostic LCD and applied source state show Movement 2x H, 0.75x V, 90° rotation and a Custom Modifier/ZOOM IN assignment, respectively. Real Virtual Mouse Lab profile unchanged.
12. **Semantic pixel Inspector:** after Connected or Shortcuts, click a visible letter of the diagnostic LCD title. **Expected:** semantic reference like `LCD/HOME/ROW_01/COL_01` and glyph's row, column, source tone and 10×14 logical pixel bounds are displayed. Clicking blank space clears the selection.
13. **Keyboard and copy:** focus diagnostic Canvas with Tab, press Enter, then arrow keys to select characters. Click Copy reference. **Expected:** matching visible reference is copied when clipboard permission allows. If denied, an explicit manual-copy instruction appears; no firmware actions are triggered by Inspector keyboard controls.
14. **Evidence files:** after running a scenario, click **Export JSON**, **Export TXT** and **Export LCD PNG**. **Expected:** browser downloads three local files (JSON scenario/hash/state, TXT human-readable local event timeline and square 240×240 PNG), with no upload or network destination. Validate JSON opens and PNG depicts the Inspector's separate LCD.
15. **Live timeline and existing functionality:** interact with real HAT or Virtual Mouse Lab while the Inspector is open. **Expected:** timeline records bounded actions, but the last isolated scenario hash does not change. Check that mobile LARGE TOUCH CONTROLS still operate at narrow widths and saved mouse profiles/shortcuts work.
16. **Regression page:** open https://remappingbridge.github.io/tests/. **Expected:** `235/235 checks passed.` If there is a FAIL, report the exact English name and browser/zoom. Isolated 235/235 alone is not live acceptance.
