2. **Correct Pico hardware:** specification says **Raspberry Pi Pico 2 W** with RP2350 and Bluetooth LE; RP2350 is a chip, not the entire board. Non-wireless **Pico 2** explicitly excluded.
3. **Correct LCD hardware:** [Waveshare Pico-LCD-1.3 SKU 19650](https://www.waveshare.com/Pico-LCD-1.3.htm) is a Pico-compatible **240×240 ST7789 SPI IPS** module with **joystick and A/B/X/Y**. Must not be confused with a full-size Raspberry Pi Linux **40-pin LCD HAT** or the 240×135 Pico-LCD-1.14.
4. **Parts table:** identifies BLE HID-over-GATT mouse, Micro-USB **data** cable (not charge-only), host USB HID, conditional **two 20-pin headers** if unpopulated, optional case/insulation and that the LCD package does **not** include Pico 2 W.
5. **Assembly SVG:** displays proper separate recognizable green Pico board and blue LCD HAT, readable RP2350/wireless/Micro-USB labels, LCD/joystick/four buttons and safe connector alignment. This conceptual drawing is **not falsely called pin-1 authoritative**.
6. **Safe assembly text:** unplug power before installation; check female HAT header vs Pico straight male pins, all **40 positions** and silkscreen/pin-1 from real maker datasheets; never force, bend, short or attach one pin-row offset.
7. **Soldering choice:** do not require soldering if a suitable Pico 2 W board already has correctly attached male headers. A bare unpopulated board needs appropriately soldered header strips; never press bare plated holes into female sockets.
8. **GPIO diagram:** verify front orientation, joystick at **left**, square display **center**, four A/B/X/Y keys **right**. JOY PRESS means pressing the joystick inward. Nine controls identified individually.
9. **GPIO source agreement:** compare table/diagram with [`hat.h`](https://github.com/remappingbridge/remappingbridge/blob/main/include/blu2usb/hat/hat.h): JOY UP GP2, PRESS GP3, LEFT GP16, DOWN GP18, RIGHT GP20; A GP15, B GP17, X GP19, Y GP21. Source `st7789_pico.c` should match SPI1 SCK GP10, MOSI GP11, D/C GP8, CS GP9, RST GP12, BL GP13.
