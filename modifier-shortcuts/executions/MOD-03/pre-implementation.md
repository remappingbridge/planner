# MOD-03 — Pre-implementation baseline, scope and constraints

**Status: CODE IMPLEMENTED / CI + PHYSICAL VALIDATION PENDING (2026-10-11).** Prior gates MOD-00, MOD-01, MOD-02 (with gray/plus corrective build) accepted by operator. Source remains the `v2.0.0` lineage in `feature/modifier-shortcuts-mod01`.

- Firmware: [feature/modifier-shortcuts-mod01](https://github.com/remappingbridge/remappingbridge/tree/feature/modifier-shortcuts-mod01), original baseline tag v2.0.0 untouched, draft PR #23 unmerged.
- Normative: [UI / flows](../../02-ui-navigation-contract.md), [migration decisions](../../05-persistence-migration.md), [MOD-00 approval](../MOD-00/operator-acceptance.md), [physical flow in firmware](https://github.com/remappingbridge/remappingbridge/blob/feature/modifier-shortcuts-mod01/docs/modifier-shortcuts/mod03-shortcuts.md).
- Implementation: five shortcut pages 1-6, 7-12, 13-18, 19-24, 25-30; 30 unique action IDs; 12 combos; 45 total screens. KEY A saves only when the existing flash slot commit/CRC verification succeeds, KEY B cancels, KEY A RESET only affects the chosen combo. Last saved value focused on reopen; no assignment initially focuses COPY. Back preserves original combo row/page. Keys process on release as in v2.
- V3 payload is 26 bytes; v2 legacy 14-byte decode remains compatible. Successful v2 migration falls back from retired profiles to PASSTHROUGH, maps old Custom/draft ESCAPE to identity, initializes all shortcuts NONE; uses existing dual flash slots and CRC record wrapper. Invalid schema/app checksum won't overwrite recognized unknown payload. BLE bonds and per-Mouse Movement are distinct, untouched.
- Limits: CUSTOM WILL BECOME retains ESCAPE until MOD-04; no physical Modifier, no UNAVAILABLE masking, no shortcut execution, no Consumer HID or USB descriptor changes. 30 actions are labels, not proven OS effects. Migration is write-on-boot from a valid v2 record, not reformat or flash_nuke. Downgrade back to v2 may lose v3 global profile settings, without touching separate Bluetooth/Movement.
- Automated tests: inherited CTest + `mod03_shortcuts_flow_and_migration` + `mod03_shortcuts_source_contract`. Production Pico 2 W UF2 must be built in CI, SHA256 validated, then physically accepted before MOD-04.
